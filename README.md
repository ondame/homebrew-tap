# ondame/homebrew-tap

Homebrew tap for the ONDA Developer Center CLI (`ondadc`).

    brew install ondame/tap/onda-developer-center
    ondadc --version
    ondadc setup

The formula is `onda-developer-center`; the installed command is `ondadc`.
Linux without Homebrew: download the archive for your platform from this repository's Releases (`cli-v<version>`) and check it against `checksums.txt`.
`ondadc mcp` runs a local stdio MCP server that relays to https://api.tport.dev/mcp.

Docs: https://developers.tport.dev/docs/cli

`Formula/onda-developer-center.rb` is generated by the CLI release workflow; do not edit it by hand.
